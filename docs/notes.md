# 作業メモ

## フェーズ1: データと生成物の品質チェック

- リンク検査は `spots/` に限定せず、リポジトリ内のHTML全体を対象にした。今後生成するカテゴリ一覧・記事・エリアページも特別な設定なしで検査でき、共通ナビなどのリンク切れも検出できるため。
- 相対リンクはHTMLファイルの置かれた階層から解決し、クエリとフラグメントを除いた実ファイルの存在を確認する。外部URL、ページ内アンカー、ルート相対URLは今回指定された「相対パスのリンク先ファイル」検査の対象外とした。
- GitHub ActionsではNode.js 20を使う。Node.js標準機能のみでビルドと検査を実行でき、ビルド後はtracked差分と未追跡ファイルの両方がないことを確認する。
