# Spot photos

Place operator-shot photos in this folder using the exact spot `slug` as the filename, for example `ohori-park.jpg`.
Supported extensions are `.jpg`, `.jpeg`, `.png`, and `.webp`. If more than one extension exists for a slug, the build chooses the first in that order.
The build uses the matching photo in generated pages and JavaScript rendered cards; otherwise it uses the image path in the spot JSON.
